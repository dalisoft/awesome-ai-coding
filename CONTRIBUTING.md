# CONTRIBUTING

## Requirements

- Changes should be related to project
- Changes should be verified
- Changes should not violate license of any of items

## Minimum requirements for new entries

Your project is checked against these rules when you open a PR. Age is counted
from the creation date of the GitHub repository. If your project does not meet
them yet, feel free to open a PR again once it does.

| Section                                                                                   | GitHub repo                 | Minimum age | Minimum stars |
| ----------------------------------------------------------------------------------------- | --------------------------- | ----------- | ------------- |
| Tools                                                                                     | Required                    | 45 days     | 30            |
| IDE & Editors                                                                             | Optional, but good to have  | 60 days     | 100           |
| Extensions, SaaS / Web-app, AI Agents, Coding Agents, Orchestrators, Resources            | Optional, but good to have  | 60 days     | 50            |
| Providers (proxy services, subscriptions, routers, tokens, subscription plan trackers)    | Not applicable              | -           | -             |

- Disclose in the PR body if you are the author or maintainer of the project
- Do not submit the same project to this list more than once
- PRs from new accounts or accounts that send the same submission to many lists
  may be closed automatically by the PR Spam Guard

## Discussing on PR or Issue

- Please read `CODE_OF_CONDUCT.md`
